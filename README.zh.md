# 小马棋盘益智游戏

纯前端（HTML / CSS / JavaScript）实现的骑士棋盘逻辑谜题，无任何第三方依赖。

在线访问: [Github Pages](https://seth-yang.github.io/knight-puzzle-game/knight-puzzle-game.html)

[English](README.md)

## 游戏规则

- 棋盘为 N×N（N = 4~10），共有 N 种颜色。
- 每行、每列有且仅有一匹小马。
- 每种颜色有且仅有一匹小马。
- 任意两匹小马不能相邻（包括斜向，即同一 3×3 九宫格内不能出现两匹）。

## 快速开始

直接用浏览器打开 `knight-puzzle-game.html` 即可。若浏览器限制本地脚本加载，可在项目目录启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/knight-puzzle-game.html`。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 单击格子 | 切换白色 ✕ 标注 |
| 快速双击同一格 | 在该格放置小马 |
| 在格子上按住拖动 | 沿路径批量添加 / 清除 ✕ 标注 |
| 修改局号后点击「开始 / 重新生成」 | 按局号生成棋盘 |
| 点击「显示答案」 | 右下角显示答案缩略图 |
| 点击「导出图片」 | 将当前棋盘保存为 PNG |

放错位置会扣 1 点生命值并锁定该格；3 点生命值耗尽则失败。首次操作即开始计时。

## 局号

局号格式为 `阶数-序列号`，例如 `6-007`、`10-056`：

- 阶数 4~10
- 序列号 1~1000（不足 3 位自动补零）
- 留空则按当前所选阶数随机开局

局号经 FNV-1a 哈希后作为 mulberry32 随机源，因此**相同局号 + 相同难度必然生成完全相同的棋盘**，便于分享与复盘。

## 难度

| 难度 | 预置小马 |
| --- | --- |
| 容易 | 2 匹 |
| 中等 | 1 匹 |
| 困难 | 0 匹 |

## 多语言

- 语言包位于 `lang/zh_CN.js` 和 `lang/en_US.js`，由 `lang/i18n.js` 按浏览器默认语言自动加载，无法匹配时回退到 `en_US`。
- 工具栏的「语言」下拉框可随时切换；静态文案以及进度、消息、弹窗、计时前缀等动态文案都会同步更新。
- 新增语言：在 `lang/` 下按现有语言包结构新建文件，在 `lang/i18n.js` 的 `SUPPORTED` 和 `detectLang()` 中注册，并在 HTML 的 `#langSelect` 中增加选项。

## 响应式布局

- 宽度 ≥ 1024px：标题、规则、工具栏、状态栏在左，棋盘与消息在右。
- 宽度 < 1024px：保持上下单列结构。

格子尺寸由 `fitBoard()` 根据视口与布局模式计算，高分屏下最大为 72px。

## 实现说明

- **谜题生成**：回溯法摆放小马 → 多源 BFS 生长颜色区域 → 局部改色直到唯一解；4~8 阶优先选择纯逻辑可解的棋盘。
- **落子判定**：不比对预存答案，而是检查落子后是否仍能补全为完整合法布局，因此符合规则的其他解同样判为正确。
- **双击判定**：以 `CLICK_DELAY`（260ms）内的同格两次点击为主，原生 `dblclick` 兜底；跨格快速点击不会被误判为双击。
- **图片导出**：使用 Canvas 按棋盘状态重绘，2 倍分辨率输出，包含颜色、小马、预置金边、判错遮罩、✕ 标注与局号。
